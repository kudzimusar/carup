# CarUp Referral AI Engine

Planning documents for the CarUp referral, reward, social channel, and AI automation system.

The system supports both local Zimbabwe marketplace activity and higher-value import flows for vehicles, parts, and container-space bookings.

AI is the operating layer. Agents assist with lead intake, code validation, campaign drafts, channel routing, trust checks, reward recommendations, analytics, and human escalation.
