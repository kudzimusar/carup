# 06 — Social Channels TRD

## Purpose

Make referral sharing work across WhatsApp, Telegram, Facebook, Instagram, web, and mobile while keeping attribution intact.

## AI use

The Channel Agent adapts one campaign into several channel versions: short copy, long copy, QR text, poster copy, group message text, and follow-up prompts.

## Acceptance criteria

- Every shared link includes campaign metadata.
- Every inbound chat can be tied to a code when one exists.
- Users can share without copying complex URLs manually.
