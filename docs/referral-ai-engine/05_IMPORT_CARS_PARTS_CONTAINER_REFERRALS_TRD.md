# 05 — Import Cars, Parts, and Container Referrals TRD

## Purpose

Prioritize higher-value import flows while keeping them connected to the local marketplace.

## Import flows

- Diaspora buyer refers another importer.
- Local receiver invites a payer abroad.
- Parts customer refers a mechanic or garage.
- Container customer refers another space booking.
- Seller or supplier refers a buyer to an import campaign.

## Container campaign model

Each container route should operate as a campaign with a route, closing date, available capacity, current utilization, QR code, short link, and campaign code.

Example campaign categories:

- Japan to Zimbabwe vehicle import.
- Japan to Zimbabwe parts order.
- UK to Zimbabwe container space.
- South Africa to Zimbabwe parts and goods.

## AI use

The Import Agent asks what the customer wants to move or buy, identifies the route, estimates the next required step, attaches referral attribution, and routes the user to quote, booking, inspection, or support.

## Milestones

Referral benefits should be tied to route milestones such as quote requested, booking confirmed, loading confirmed, delivery confirmed, or review window closed.

## Acceptance criteria

- Import and local flows share member identity.
- Container-space campaigns expose availability and closing urgency.
- Referral attribution remains connected through quote, booking, and delivery workflows.
