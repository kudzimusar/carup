# 04 — Local Marketplace Referrals TRD

## Purpose

Support local marketplace sharing while import campaigns remain the higher-value priority.

## Local flows

- Customer to customer.
- Seller to customer.
- Mechanic to parts customer.
- Supplier to garage or reseller.
- Community member to listing.
- Local operator to offline customer.

## Journey

A user shares a code or QR card. The new user opens the link or scans the code. AI triage identifies the need, creates a lead or listing draft, and routes the case for review when required.

## AI use

The local AI flow helps create listings, describe parts, classify vehicle details, draft listing text, and suggest a campaign code.
