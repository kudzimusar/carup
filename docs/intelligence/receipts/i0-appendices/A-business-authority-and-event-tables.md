## 4. RLS / TENANCY PATTERNS (standard idioms, with refs)

1. **Service-role-only tables** (dominant modern pattern): `ENABLE ROW LEVEL SECURITY` with ZERO policies + `REVOKE ALL FROM anon, authenticated` + `GRANT ALL TO service_role` — default-deny for API roles, backend (Express service-role client) bypasses RLS. E.g. `navigation_analytics_events` (`20260623130000:87-90`), `trust_audit_events` (`20260603233640:40-44`), `marketplace_inquiries` (`20260616120000:71-73`), `vehicle_reservations` (`20260819110000:38-40`).
2. **`current_tenant_id()`** = `NULLIF(current_setting('app.current_tenant', true),'')::UUID` (`002:170-173`), used in `tenant_vehicles_isolation` policy on vehicles (`002:177-180`, incl. the `tenant_id IS NULL` permissive branch later flagged). Session-variable pattern, not JWT.
3. **JWT-claim tenant scoping** (comms family): `auth.jwt()->'app_metadata'->>'tenant_id'` + role allowlist, fail-closed when claim absent (`20260705170000:46-57`).
4. **`auth.uid()::text` participant/ownership policies** (diaspora family, `013:535-621`; escrow participant read `20260626180000:88-96`); recursion fixed in `014_diaspora_rls_recursion_fix`; SECURITY DEFINER helper fns with pinned search_path for participant checks (`20260811131500:231+`).
5. **Immutability enforcement**: BEFORE UPDATE/DELETE triggers raising (`governance_block_mutation` for escrow events; `carup_provenance_block_mutation` `20260621120000:214`; `carup_listing_snapshot_block_mutation`; trust_change_log immutability `20260624150000`); plus grant-shaped append-only (no UPDATE/DELETE granted, `20260705170000:60-64`).
6. **Progressive containment history**: `20260619201406_production_access_containment` (revoked client roles from 11 server-owned tables incl. saved_vehicles, domain_events, financial_ledger); `20260620232827` follow-up; `20260809110000_api_role_write_hardening` (write-side revocation on mechanic_work_orders/parts, vehicle_ownership_history, vehicle_evidence, vehicles — left `vehicles_public_read USING(true)` to Issue #101); `20260814090000` issue101 P0 RLS+view hardening; final anon SELECT revocations on vehicles + vehicle_evidence (`20260825090000/090100` — anon could read 66 columns incl. owner_id/plate/chassis/engine before this).
7. **Idempotency-key idiom**: `idempotency_key TEXT UNIQUE` on mutation-target tables (escrow_trust_sessions, vehicle_reservations, escrow_trust_webhook_events, referral_coupon_redemptions); partial unique indexes over JSONB-extracted keys (`20260715205718`); RPC-based atomic mutations with row locks (`issue164_reserve_vehicle_atomic`, diaspora H1–H3 RPCs).
