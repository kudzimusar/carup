# CarUp Agent Prompt Policy

Long or multi-step agent instructions must be stored as Markdown files in this directory and referenced by repository path in every future agent request.

Project and thread handoffs belong in `docs/handoffs/`.

Do not rely on chat memory or uploaded files as the only copy of an important instruction.

Do not commit secrets, credentials, signed URLs, private evidence, or personal documents.

For Phase 7C, read:

- `docs/agent-prompts/PHASE_7C_STAGING_READINESS.md`
- `docs/handoffs/PHASE_7C_VERIFICATION_CASE_MANAGEMENT_HANDOFF.md`
